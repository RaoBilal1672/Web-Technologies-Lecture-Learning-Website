Lecture 04: HTML5 Forms & Validation

The <form> Element

  • action: URL where form data is sent.
  • method: HTTP method (GET or POST).
  • GET: Data sent via URL (suitable for small data).
  • POST: Data sent in request body (for secure, large data).

Common Form Elements

  • <label> — Associates text with a control.
  • <input> — Most versatile element (text, email, password, checkbox, radio, etc.).
  • <select> — Dropdown selection.
  • <textarea> — Multi-line input.
  • <button> — Submit / reset / action.
  • <fieldset> + <legend> — Group related controls.

HTML5 Input Types

New input types include: email, date, number, range, color, month, time, week, search, tel, url, file, hidden.

HTML5 Validation Attributes

  • required: Field cannot be empty.
  • pattern: Regular expression for format validation.
  • min / max: Numeric boundaries.
  • placeholder: Hint text that disappears on typing.
  • autofocus: Automatically focuses the field.

Client vs. Server Validation

  • Client-side: Fast feedback, improves UX (required, pattern, min/max).
  • Server-side: Essential for security, re-validates input, business rules.

Golden rule: Client = convenience • Server = authority.
