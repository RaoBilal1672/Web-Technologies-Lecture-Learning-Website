 Web Technologies – Lecture Learning Website

Project Overview

Web Technologies is a simple educational website developed as part of my Web Technologies course. The project demonstrates the fundamentals of HTML and CSS through a clean, organized, and user-friendly multi-page website.

##Features

- **Homepage:** Displays the student's name and registration number.
- **Lecture Table:** Lists eight lectures with lecture numbers and titles.
- **Clickable Links:** Each lecture includes a hyperlink to its respective webpage.
- **Lecture Summaries:** Separate webpages provide brief summaries of all eight lectures.
- **CSS Styling:** Improves the website's layout, readability, colors, and overall appearance.

## Technologies Used

- HTML5
- CSS3

##  How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Click the lecture links to explore the lecture summaries.
